## 공통 모듈

### `auth_fetch.js` — 인증 API 공용 래퍼

모든 API 호출에 사용하는 공통 함수. 모든 페이지에서 로드됨.

**핵심 기능:**
- `apiFetch(url, options)` : 기본 `fetch`와 동일한 사용법. `sessionStorage` 또는 `localStorage`에서 JWT 토큰을 자동으로 꺼내 `Authorization: Bearer {token}` 헤더에 부착
- 응답이 `401` 또는 `403`이면 세션 정리 후 `login.html`로 자동 리다이렉트
- `consumeSessionExpiredFlag()` : 로그인 페이지에서 세션 만료 안내 배너 표시용

**토큰 저장 위치:**
- 로그인 시 "로그인 유지" 체크 → `localStorage`
- 체크 안 함 → `sessionStorage`

### `disease_map.js` — 질환 매핑 데이터

AI 모델이 분류하는 11종 질환의 한글명/영문명/키 매핑 정보.

**11종 질환 목록:**
| key | 한글명 | 영문명 |
|---|---|---|
| psoriasis | 건선 | Psoriasis |
| atopic_dermatitis | 아토피피부염 | Atopic Dermatitis |
| acne | 여드름 | Acne Vulgaris |
| actinic_keratosis | 광선각화증 | Actinic Keratosis |
| basal_cell_carcinoma | 기저세포암 | Basal Cell Carcinoma |
| melanocytic_nevi | 멜라닌세포모반 | Melanocytic Nevi |
| melanoma | 악성흑색종 | Melanoma |
| seborrheic_keratosis | 지루각화증 | Seborrheic Keratosis |
| squamous_cell_carcinoma | 편평세포암 | Squamous Cell Carcinoma |
| dermatofibroma | 피부섬유종 | Dermatofibroma |
| vascular_lesion | 혈관종 | Vascular Lesion |

**제공 함수:**
- `VALID_DISEASES` : 전체 배열
- `DISEASE_MAP` : `key → { ko, en }` 객체 lookup
- `DISEASE_KO_TO_KEY` : 한글명 → key 역매핑
- `diseaseByKoName(nameKo)` : 한글명으로 질환 객체 반환
- `getDiseaseLabel(key)` : key로 한글명 반환

> Flask AI 서버(`ai/inference/app.py`)의 클래스 순서와 반드시 일치해야 함

## 인증 관련

### `login.js` — 로그인 처리

**주요 로직:**
1. 이메일 형식 유효성 검사 (클라이언트)
2. `POST /api/auth/login` 호출
3. 성공 시 JWT 토큰과 유저 정보를 storage에 저장
   - "로그인 유지" 체크 → `localStorage`, 미체크 → `sessionStorage`
4. 로그인 시각(`loginTime`)과 기기 UA(`loginUA`)도 함께 저장
5. 0.8초 후 `dashboard.html`로 이동
6. 세션 만료 후 리다이렉트된 경우 안내 배너 표시

**API 엔드포인트:** `POST /api/auth/login`

---

### `signup.js` — 회원가입 처리

**주요 로직:**
1. 역할 선택: 전공의 / 의대생 (기본값: 전공의)
2. 이메일 중복 확인 (400ms 디바운스 → `GET /api/auth/check-email`)
3. 비밀번호 강도 측정 (약함/보통/강함 3단계)
4. 비밀번호 확인 일치 여부 실시간 검사
5. 개인정보 동의 페이지(`privacy_consent.html`)로 이동 전 폼 데이터를 `sessionStorage`에 임시 저장
6. 동의 완료 후 돌아오면 폼 데이터 자동 복원
7. `POST /api/auth/signup` 호출 → 성공 시 완료 카드 표시

**개인정보 동의 연동:**
- 동의 완료 → `sessionStorage.privacyConsent = 'true'`
- 미동의 상태로 가입 시도 시 오류 표시

---

### `privacy_consent.js` — 개인정보 동의

**10개 섹션 구성:**
개인정보보호법·의료법 기반 10개 필수 동의 항목 (수집목적/민감정보/마스킹/접근범위/제3자제공/보유기간/거부권/권리행사/안전조치/의료법)

**주요 로직:**
- 각 섹션 아코디언 방식으로 펼치기/접기
- 동의 / 비동의 선택 → 동의 시 다음 섹션 자동 오픈
- 진행률 바 실시간 업데이트
- 10개 전체 동의 완료 시 제출 버튼 활성화
- 완료 → `sessionStorage.privacyConsent = 'true'` 저장 후 `signup.html`로 이동

---

### `forgot_password.js` — 비밀번호 찾기

**로직:**
1. 이메일 입력 및 형식 검증
2. `POST /api/auth/forgot-password` 호출
3. 성공 시 "발송 완료" 화면 전환 (15분 유효 안내)

---

### `reset_password.js` — 비밀번호 재설정

**로직:**
1. URL 쿼리스트링에서 `token` 파라미터 추출
2. `GET /api/auth/verify-reset-token?token=...` 으로 토큰 유효성 확인
3. 유효하지 않으면 오류 화면 표시
4. 비밀번호 강도 측정 (5단계: 매우약함/약함/보통/강함/매우강함)
5. `POST /api/auth/reset-password` 호출 → 성공 시 완료 화면

## 메인 기능

### `ai_analyze.js` — AI 피부 분석 (핵심)

**이미지 업로드 처리:**
- 드래그앤드롭 또는 파일 선택
- 10MB 초과 파일 차단
- 이미지 미리보기 표시

**분석 흐름:**
1. `POST /api/analyze/upload` → 서버에 이미지 업로드 (서버에서 EXIF 제거·마스킹 처리)
2. 3단계 로딩 애니메이션 실행 (업로드와 병렬)
3. `POST /api/analyze/run` → AI 분석 실행
4. 결과 표시:
   - 진단명 (한글/영문), 신뢰도 %
   - 신뢰도 바 애니메이션
5. AI 소견(LLM 리포트):
   - 분석 응답에 포함된 경우 즉시 표시
   - 없으면 로딩 중 표시 후 `POST /api/analyze/report`로 별도 비동기 요청
6. 임상 통계 (연령분포, 성별분포, 주 중증도) 표시

**에러 처리:**
- `uncertain` 결과 → 에러 카드 + 지원 질환 목록 표시
- AI 서버 미연결 (`API_NOT_CONNECTED`) → 별도 안내
- 세션 만료 → 로그인 페이지 자동 이동

**LLM 채팅:**
- 진단 완료 후 채팅창 표시
- `POST /api/analyze/chat` 으로 질문 전송
- 채팅 내역은 `chatHistory` 배열에 세션 보관

**기록 저장:**
- `POST /api/records` 호출
- 저장 데이터: 이미지 URL, 진단명, 신뢰도, Grad-CAM, 임상 통계, AI 소견, 채팅 기록

### `my_analyze.js` — 분석 기록 목록

**주요 기능:**
- `GET /api/records` 로 전체 기록 로드
- 필터링: 질환별 칩 버튼, 날짜 범위 (1주/1개월/3개월), 정렬 (최신/신뢰도 높음/낮음)
- 페이지네이션 (페이지당 5건)
- 신뢰도 링 SVG 애니메이션 (고신뢰 80%↑ 녹색, 중신뢰 65%↑ 주황, 저신뢰 빨강)
- 통계 카드: 전체 건수, 이번 주, 이번 달 (전월 대비 증감), 학습 질환 수
- 도넛 차트: 질환별 분포 (Chart.js)
- 월별 바 차트: 최근 6개월 분석 건수 (Chart.js)
- 스트릭 캘린더: 최근 35일 학습 현황 (레벨별 색상)
- 기록 삭제: `DELETE /api/records/:id`
- 기록 클릭 → `record_detail.html?id=...` 이동

---

### `record_detail.js` — 분석 기록 상세

**주요 기능:**
- URL 쿼리스트링 `?id=...` 로 기록 ID 파악
- `GET /api/records/:id` 로 상세 데이터 로드
- 표시 항목:
  - 진단명 (한국어/영어), AI 신뢰도, 분석 날짜
  - 원본 이미지
  - Grad-CAM 열지도 (원본/히트맵 비교, 데이터 있을 때만 표시)
  - 신뢰도 링 애니메이션 (SVG)
  - AI 소견 (요약/특징/권고/면책고지)
- 저장된 채팅 기록 복원 및 표시
- LLM 채팅: `POST /api/analyze/chat`
- 채팅 메시지 저장: `PATCH /api/records/:id/chat`
- 북마크 토글 (UI만 구현, API 미연동)
- 공유: Web Share API 또는 클립보드 복사

## 설정·계정

**탭 구성**: 프로필 정보 / 계정 정보 / 알림 설정 / 데이터 관리

**주요 기능:**

- 이름·역할·소속 수정 → localStorage/sessionStorage 유저 정보 동기화

- 데이터 내보내기: `GET /api/analyze/records` → CSV 다운로드
- 학습 기록 초기화: `DELETE /api/analyze/records`
- 계정 탈퇴: `'탈퇴합니다'` 입력 확인 후 모달 처리
- 학습 통계 로드: `GET /api/records` → 총 분석 수, 학습 질환 수, 연속 학습일 계산

### `withdraw.js` — 회원 탈퇴

**로직:**
1. 탈퇴 사유 라디오 선택 (기타 선택 시 직접 입력창 표시)
