# SkinAI 프론트엔드 이슈 체크

> 심각도: 🔴 버그(동작 오류) / 🟠 미구현(UI만 있고 실제 기능 없음) / 🟡 주의(잠재적 문제) / 🟢 정상

## 1. dashboard.js — 시간대별 인사말 작동 여부 🟢 정상 (조건부)

**파일:** `src/dashboard.js` L18~38

**결론: 실제로 작동함.**

`id="greetTitle"`, `id="greetRole"` 요소가 `dashboard.html` L178~179에 실제 존재함. 로그인 후 `localStorage` 또는 `sessionStorage`에 `user` 정보가 저장되어 있으면 이름·역할이 정상 표시됨.

**단, 주의사항:**
- 비로그인 상태 직접 접근 시 → "안녕하세요, 사용자님" + 빈 역할 표시
- 로그인 페이지에서 정상 로그인 후 이동한 경우에만 이름이 제대로 뜸

## 2. profile.js — 비밀번호 변경이 실제로 안 됨 🔴 버그

**파일:** `src/profile.js` L194~205

```js
function changePw() {
  // 유효성 검사 후...
  openModal('pwSuccessModal');  // ← "변경 완료" 모달만 뜸
  // API 호출이 없음!
}
```

"비밀번호가 변경되었어요" 모달이 뜨지만 실제 서버에 변경 요청을 보내지 않음. **현재 비밀번호 확인도 없이** 바로 성공 처리됨.

**필요 API:** `POST /api/auth/change-password` (또는 해당 엔드포인트)

## 4. community.js — 전체가 더미 데이터 🟠 미구현

**파일:** `src/community.js`

### 4-1. 로그인 유저가 하드코딩됨
```js
const ME = { id:'user_me', author:'김전공', role:'resident', ... };
```
실제 로그인한 사용자 정보를 사용하지 않음. 게시글 작성자가 항상 "김전공"으로 표시됨.

### 4-2. 게시글이 메모리에만 존재
게시글 배열 `posts`가 JS 메모리에만 있음. 새로고침하면 작성한 게시글이 모두 사라지고 더미 3개로 초기화됨. 실제 API 연동 없음.

### 4-3. 미디어 업로드가 가짜 로딩
`submitPost()`의 업로드 오버레이가 실제 파일 업로드 없이 700ms~1300ms 타이머로만 진행됨.

navigator.clipboard.writeText(`https://skinai.kr/community/${id}`)

## 6. login.js — finally 블록 색상 비교 불안정 🟡 주의

**파일:** `src/login.js` L81

```js
if (btn.style.background !== 'rgb(5, 150, 105)') {
  btn.classList.remove('loading');
  btn.disabled = false;
}
```

로그인 성공 후 버튼을 비활성화 유지하려는 의도인데, 브라우저마다 색상 포맷 반환 방식이 다를 수 있음 (예: Safari에서 다른 포맷). `boolean` 플래그 변수로 대체하는 것이 안전함.
