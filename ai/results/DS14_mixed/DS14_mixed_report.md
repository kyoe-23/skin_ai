# DS14 혼합 학습 결과 보고서 — SkinAI DenseNet121 + DermNet NZ

## 1. 학습 개요

- **모델**: DenseNet121 (ImageNet pretrained)
- **클래스**: 건선, 아토피피부염, 여드름, 주사, 지루피부염, 정상 (6종)
- **기반 데이터**: AI Hub 08-14 합성 이미지 9,600건 (정면+측면)
- **외부 데이터**: DermNet NZ 실제 임상 이미지 3종 (건선·아토피피부염·여드름) — train/val/test 분리
- **샘플링 전략**: WeightedRandomSampler — AI Hub weight=1.0, DermNet weight=1.5
- **학습 환경**: Google Colab (RTX PRO 6000, 97GB VRAM 로컬 포함)
- **목적**: 합성 → 실제 이미지 도메인 갭 완화

## 4. 주요 발견

### 4.1 여드름 도메인 갭 해소 (Recall 5.1% → 92.6%)

DS14 baseline에서 여드름 recall이 5.1%로 사실상 분류 불능이었던 원인은
AI Hub 합성 여드름 이미지와 DermNet 실제 여드름 이미지의 시각적 분포 차이(조명·배경·병변 표현 방식)가 극단적으로 달랐기 때문.
DermNet 데이터를 외부 소스로 추가하자 recall이 92.6%로 복원됨.

### 4.2 best_epoch 지연 (14 → 40)

두 도메인의 데이터 분포가 달라 최적점에 수렴하는 데 baseline보다 26 에폭 더 필요.
AI Hub 합성 분포에 빠르게 적합한 후 DermNet 실제 이미지 분포까지 함께 학습하는 과정이 반영됨.

### 4.3 AI Hub val 소폭 하락(-0.77%p)은 허용 범위

DermNet 3종만 포함되어 주사·지루피부염·정상 클래스는 AI Hub 합성 데이터만으로 학습.
혼합 학습의 정규화 효과로 AI Hub val 자체는 가이드라인 목표(80%)를 11.5%p 상회.

## 5. 한계 및 후속 과제

| 항목 | 내용 |
|------|------|
| 주사·지루피부염·정상 실사 평가 | DermNet에 해당 클래스 없음 → 별도 실제 이미지 수집 필요 |
| 실사 테스트 규모 | 클래스별 10장(총 30장)으로 통계적 신뢰도 제한적 |
| DermNet 데이터 편향 | DermNet 건선 폴더에 Lichen Planus(태선) 혼입 → 건선 AUC 0.922로 다소 낮음 |
| 미평가 데이터 | ISIC 2019, HAM10000 등 추가 외부 데이터셋 평가 미완료 |

## 6. 결론

- AI Hub val Top-1 **91.50%** (가이드라인 목표 80% 대비 +11.5%p 달성)
- DermNet test Top-1 **82.30%** (baseline 35.77% 대비 **+46.53%p** 향상)
- 여드름 Recall: **5.1% → 92.6%** — 가장 큰 도메인 갭 해소
- Flask `/predict` 실사 추론: **86.7%** (3종 30장 기준)
- **혼합 학습이 합성 전용 모델의 실제 이미지 일반화 한계를 크게 개선함을 확인**
