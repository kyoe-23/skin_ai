# DS15 혼합 학습 결과 보고서 — SkinAI DenseNet121 + ISIC 2019

## 1. 학습 개요

- **모델**: DenseNet121 (ImageNet pretrained)
- **클래스**: 15종 (광선각화증·기저세포암·멜라닌세포모반·보웬병·비립종·사마귀·악성흑색종·지루각화증·편평세포암·표피낭종·피부섬유종·피지샘증식증·혈관종·화농 육아종·흑색점)
- **기반 데이터**: AI Hub 08-15 합성 이미지 12,000건 (train.csv 전체)
- **외부 데이터**: ISIC 2019 실제 임상 이미지 11,569건 (8종 매핑, DS15 class_idx 기준)
- **샘플링 전략**: WeightedRandomSampler — AI Hub weight=1.0, ISIC weight=1.5
- **학습 환경**: Google Colab (RTX PRO 6000 로컬 + Colab GPU)
- **목적**: 합성 → 실제 이미지 도메인 갭 완화 (DS14_mixed와 동일 전략을 15종으로 확장)

## 4. 주요 발견

### 4.1 ISIC 도메인 갭 대폭 해소 (Top-1 26.40% → 77.72%)

DS15 baseline에서 ISIC 2019 실제 이미지 Top-1이 26.40%였던 원인은 AI Hub 합성 이미지와 ISIC 임상 이미지의 시각적 분포 차이(조명·배경·촬영 각도·병변 표현 방식)가 극단적으로 달랐기 때문. ISIC 11,569건을 외부 소스로 추가하자 Top-1이 77.72%로 +51.32%p 향상됨.

### 4.2 AI Hub val 소폭 하락(-0.26%p)은 허용 범위

ISIC 2019에서 8종만 포함되어 나머지 7종(보웬병·비립종·사마귀·표피낭종·피지샘증식증·화농 육아종·흑색점)은 AI Hub 합성 데이터만으로 학습. 혼합 학습의 정규화 효과로 AI Hub val 자체는 여전히 99.67%로 매우 높은 수준 유지.

### 4.3 피부섬유종·혈관종의 소수 샘플 고성능

ISIC val 내 피부섬유종(36건)·혈관종(38건)은 support가 적음에도 AUC 0.997·0.982로 최상위권. 모델이 시각적으로 특이한 병변 패턴을 효과적으로 학습함.

### 4.4 편평세포암 recall 저조 (0.585)

ISIC val 내 편평세포암이 94건으로 상대적으로 적고 광선각화증과 시각적으로 유사해 혼동 발생. AUC는 0.970으로 높아 경계 사례가 집중적으로 틀리는 패턴.

## 5. 한계 및 후속 과제

| 항목 | 내용 |
|------|------|
| DS15 test split 없음 | train.csv 12,000장 전부 학습에 사용 → holdout test 세트 없음. 3-way split 후 재학습 필요 |
| 7종 ISIC 미포함 | 보웬병·비립종·사마귀·표피낭종·피지샘증식증·화농 육아종·흑색점은 실제 이미지 평가 불가 |
| 실사 테스트 규모 | 클래스별 15장(총 120장)으로 통계적 신뢰도 제한적 |
| 편평세포암 추가 데이터 | ISIC val 94건으로 소규모 — HAM10000 추가 혼합 시 recall 개선 예상 |
| DS14 6종 클래스 미포함 | DS15는 DS14 클래스(건선·아토피피부염·여드름·주사·지루피부염·정상)와 다른 카테고리 — 통합 모델 필요 시 별도 구조 설계 필요 |
