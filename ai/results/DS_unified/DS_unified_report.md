## 1. 학습 개요

- **모델**: DenseNet121 (ImageNet pretrained)
- **클래스**: 11종 — DS14 3종 (건선·아토피피부염·여드름) + DS15 8종 (광선각화증·기저세포암·멜라닌세포모반·악성흑색종·지루각화증·편평세포암·피부섬유종·혈관종)
- **제외 클래스**: DS14 3종 (주사·지루피부염·정상), DS15 7종 (보웬병·비립종·사마귀·표피낭종·피지샘증식증·화농 육아종·흑색점) — 외부 임상 데이터 미확보
- **학습 환경**: Google Colab (NVIDIA A100-SXM4-80GB, 179GB RAM)
- **목적**: DS14_mixed + DS15_mixed 두 모델을 단일 11종 통합 모델로 통합, 단일 Flask 엔드포인트로 서빙

## 6. 주요 발견

### 6.1 통합 클래스 성능 안정적 확보

DS14_mixed (6종)과 DS15_mixed (15종)을 분리 학습하던 구조에서 11종 단일 모델로 통합했음에도 각 도메인 실사 성능이 유지·향상됨:
- DermNet (건선·아토피·여드름): 82.30% → 82.48% (동등)
- ISIC (악성 8종): 77.72% → 80.12% (+2.4%p 향상)

### 6.2 HAM10000 소수 클래스 보강 효과 확인

ISIC val 소수 클래스 대비 DS15_mixed:
- DS_unified 전체 ISIC val Weighted F1: 0.7764 → 0.8226 (+0.046)
- HAM10000이 광선각화증(+327건)·기저세포암(+514건)·멜라닌세포모반(+6,705건)을 보강해 중위권 클래스 안정성 향상 기여

### 6.3 epoch 2 급격한 수렴 (14% → 73%)

warmup 1 에폭(10.7%)에서 warmup 2 에폭(72.9%)으로 급격히 상승. 30,385건이라는 대규모 혼합 데이터에서 warm LR이 모델의 초기 수렴을 가속한 결과.

### 6.4 I/O 병목 ZIP 방식으로 해소

외부 데이터(DermNet/ISIC/HAM10000)를 개별 JPEG 파일로 Drive에서 읽으면 에폭당 22분 소요. ZIP_STORED 포맷 1개 파일로 묶은 후 Drive OS 페이지 캐시(179GB RAM)가 2 에폭부터 워밍업돼 에폭당 217초(3.6분)로 단축.
